# 08 - UI 产品化改造详细设计

> 状态：已批准 · 日期：2026-10-22 · 依据：docs/07 UI 原型图 · 技术栈：Vue3 + TypeScript（hash 路由）

## 1. 目标

把当前"可用工具"界面升级为"专业产品"质感：以 docs/07 的 5 张原型图为基准，统一设计令牌、强化品牌 Header、参数分区化、状态可视化，不改动后端 API 与业务逻辑。

## 2. 现状差距分析（已逐页核对）

| 页面 | 现状 | 与原型差距 |
|---|---|---|
| 全局 | header 顶栏 + 左侧模型侧栏 + 主区/结果区 | 原型为左侧导航；卡片质感弱（无分组标题徽标）；空状态朴素 |
| 文生图 | 参数平铺在一个卡片 | 原型参数分区（模型区/提示词区/画布与采样区）；模型区带徽标 |
| 图像编辑 | 参数平铺 | 同文生图：分组化 + 对比标签徽章 |
| 放大 | 单张/文件夹切换，结果用 gallery | 原型有"文件列表表格"（名称/原尺寸/目标/状态/耗时） |
| 扩图 | 方向 chips + 描述 + 结果对比 | 基本一致，补分区与结果徽章 |
| 提示词优化弹窗 | 已实现（原文/结果/应用/复制/关闭） | 与原型一致，微调间距 |

## 3. 设计令牌（全局 style 变量扩展）

在 `src/styles/global.css` 扩展，不破坏现有变量：

```css
--panel-title-size: 15px;
--radius-sm: 6px;            /* 徽标、小控件 */
--header-h: 56px;
--section-gap: 14px;         /* 参数组间距 */
--card-hover: rgba(59,130,246,.06);
--gradient-brand: linear-gradient(135deg,#3b82f6,#8b5cf6); /* Logo/进度 */
--font-size-xs: 11px;        /* 徽标/辅助文本 */
```

## 4. 组件级改造规格

### 4.1 AppHeader（品牌化）
- 高度 56px，左侧 Logo：渐变圆角方块（`--gradient-brand`）内"AI" + 名称"AI 图像工作站"（加粗 15px）
- 中部导航 tabs 保持，激活态改为**品牌渐变底 + 白字**（替代纯蓝）
- 右侧：GPU 状态迷你徽标（绿点 + "GPU 就绪"，数据来自 ModelSidebar 同 store）+ 设置/帮助图标
- 底部加 1px 渐变分隔线（primary → transparent）

### 4.2 页面布局（4 个 view 统一）
每个 view 的 `workspace` 改为：
```
.grid 360px 1fr
  ├─ 左：操作卡片（section.panel.card）
  │    ├─ h2.panel-title（带功能图标）
  │    ├─ div.field-group（参数分区，带 .group-label）
  │    │   ├─ 模型区：ModelSelector + 当前模型徽标（.badge-model）
  │    │   ├─ 提示词区：prompt-head + textarea + AI优化
  │    │   ├─ 画布与采样区：比例/步数/种子（.fields-grid 两列）
  │    │   └─ 执行区：错误提示 + 主按钮（渐变）+ 队列提示
  │    └─ …
  └─ 右：结果卡片（面板标题带任务状态徽标）
```

### 4.3 组件复用与新增
| 组件 | 动作 | 说明 |
|---|---|---|
| `FieldGroup.vue`（新） | 新增 | 参数分区容器：`<FieldGroup title="生成设置">` 渲染分组标签+分隔线 |
| `Badge.vue`（新） | 新增 | 状态徽标：`type=ok/warn/idle/brand`，12px 圆角胶囊 |
| `AppHeader.vue` | 改造 | 品牌 Logo、渐变激活态、GPU 迷你徽标 |
| `ModelSelector.vue` | 微调 | 选项带模型徽标（FLUX/Z/SANA 各自 4 步/8 步/2 步提示） |
| 4 个 view | 改造 | 分区化 + 徽标 + 主按钮渐变 + 空状态文案优化 |

### 4.4 放大页：文件列表表格
结果区增加 `table.file-table`（仅 folder 模式显示）：
列：文件名 | 原尺寸 | 目标尺寸 | 状态（成功绿✓/失败红✗） | 耗时
数据源：任务 detail 的 `outputs` 元信息（含 `original_size/target_size/elapsed`，后端已返回）。

### 4.5 交互与状态
- 主操作按钮：`background: var(--gradient-brand)`，hover 提亮；disabled 降透明度
- 结果面板标题右侧：任务状态徽标（进行中=橙色 spinner 徽标 / 成功=绿 / 空=灰）
- 空状态：图标（emojis 免用，用 CSS 圆点/插画色块）+ 引导文案

## 6. 验收标准

1. 4 个功能页布局分区清晰、信息层级一致（分区标签 > 控件 > 徽标）
2. 品牌感：渐变 Logo、渐变主按钮、激活 tab 渐变，无突兀色块
3. 状态可视化：任务进行/成功/排队均有徽标反馈
4. `npm run build` 零错误；hash 路由全部可访问；后端 API 零改动
5. 与 docs/07 原型图视觉对齐度 ≥80%（布局分区与元素齐全）
