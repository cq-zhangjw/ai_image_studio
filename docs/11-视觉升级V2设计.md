### 3.3 顶栏

## 6. 画廊卡片交互升级（用户追加）

> 动因：主页画面不应只有图，还应展示提示词/模型/参数；支持「做同款」一键复刻与点击放大。

### 6.1 后端
- `schemas.py` `TaskDetail` 增加 `params: Optional[dict]`
- `task_manager.py` `to_detail` 输出 `params=dict(self.payload)`（完整提交参数，供回填）

### 6.2 前端
- **卡片常驻信息区**（图下方）：提示词 2 行截断（title 全量）、类型胶囊（文生图/编辑/放大/扩图）、模型名、尺寸、步数
- **hover 遮罩**：居中两个按钮——`✨ 做同款`（仅 `type==='text-to-image'` 且有 `params` 时显示）、`👁 查看大图`
- **做同款**：`stores/reuse.ts`（Pinia）`setPending(type, params)` → `router.push('/workspace/{type}')` → `TextToImageView` onMounted `applyReuse()` 回填 prompt/negative/model/ratio/steps/seed
- **Lightbox**：点击图片打开大图预览（关闭/左右切换/Esc），底部展示 prompt + 模型参数元数据
- **图片加载健壮性**：URL 带 `?t={stamp}` cache-buster + `@error` 三次重试（递增时间戳）+ `loading="lazy"` + `decoding="async"`（eager 全量加载在并发下会大量失败，lazy 为必须）
- **taskMap 精确匹配**：按输出路径中的批次时间戳 `\d{8}_\d{6}` 匹配任务，替代 basename 匹配（同名 `output_01.png` 会误配到其他任务的模型/参数）

### 6.3 验证
1. `npm run build` 零错误
2. CDP 端到端：点击做同款 → hash 变为 `#/workspace/text-to-image` → 输入框回填 prompt/model 正确
3. 像素级验证：三列图片区 stddev>20（图片真实渲染）；Lightbox 打开/关闭/切换正常
4. 历史任务未持久化的批次（早于 moofile 落库）无任务匹配 → 只显示提示词，不显示误配模型参数
