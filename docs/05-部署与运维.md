# 05 · 部署与运维

> 版本：v0.1 · 2026-10-21

## 1. 环境要求

| 项 | 要求 |
|---|---|
| OS | Windows（开发与运行目标；macOS/Linux 需微调路径） |
| GPU | RTX 3080 20G（或同档 ≥16G；显存不足时降低 target_area） |
| Python | 3.12（项目 venv：`E:\my_projects\qwen-2.1\.venv`） |
| Node | ≥ 18（开发机已装 v20.20.2） |
| 模型 | `models/`：Qwen-Image-2.1 / ERNIE-Image-INT8 / Lumina-Image-2.0 / MOSS-Image-SFT / FLUX.2-klein-4B / Z-Image-Turbo / Sana-Sprint-1.6B / Qwen3.5-4B-Instruct；`models/realesrgan`（ncnn-vulkan 二进制 61MB） |

## 2. 后端启动

```powershell
cd E:\my_projects\qwen-2.1
# 首次：安装依赖（已含 torch/diffusers 等；仅新增 Web 依赖）
.\.venv\Scripts\python.exe -m pip install fastapi "uvicorn[standard]" python-multipart sse-starlette

# 启动（默认 127.0.0.1:8000）
.\.venv\Scripts\python.exe backend\run.py
```

验证：`curl http://127.0.0.1:8000/api/health` → `{"status":"ok",...}`

## 3. 前端开发/构建

```powershell
cd E:\my_projects\qwen-2.1\frontend
npm install
npm run dev        # http://127.0.0.1:5173（/api 代理到 8000）
npm run build      # 产出 dist/，vue-tsc 类型检查
```

## 4. 部署模式

- **开发**：前后端分离，Vite dev server 代理 `/api`。
- **生产（单端口）**：`backend/run.py --serve-frontend` 时把 `frontend/dist` 挂到 `/`，
  访问 `http://127.0.0.1:8000` 即完整应用。
- **生产（分离）**：dist 部署到任意静态服务器，`VITE_API_BASE` 指向后端。

## 5. 配置项（backend/app/config.py）

| 键 | 默认 | 说明 |
|---|---|---|
| `PROJECT_ROOT` | 仓库根 | 自动推导 |
| `OUTPUT_DIR` | `<root>/outputs` | 产物目录（历史画廊） |
| `UPLOAD_DIR` | `<root>/outputs/_uploads` | 上传临时目录（任务完成后保留） |
| `MODEL_ROOT` | `<root>/models` | 模型根 |
| `QWEN_MODEL_DIR` | `<root>/models/Qwen-Image-2.1` | Qwen 权重 |
| `MAX_UPLOAD_MB` | 20 | 单文件上限 |
| `MAX_TASK_PIXELS` | 4_000_000 | 生成图面积上限（防 OOM） |
| `PORT` / `HOST` | 8000 / 127.0.0.1 | uvicorn 绑定 |

## 6. 运维要点

- **OOM 防护**：串行队列 + 面积上限 + offload；若仍 OOM，任务返回 `failed` 并附带
  `torch.cuda.memory_*` 快照，前端提示"降低尺寸/步数重试"。
- **首次任务慢**：模型懒加载 20~28s，属正常；任务详情含 `model_load_seconds`。
- **Real-ESRGAN**：ncnn-vulkan 推理（不占 CUDA 显存），~5s/张；2x/3x/4x 由 x4plus 4x 超分 + LANCZOS 缩放实现。
- **日志**：uvicorn 标准输出；任务错误写入 `outputs/<stamp>/task_error.log`。
- **端口占用**：`netstat -ano | findstr :8000` 排查；`run.py` 支持 `--port` 覆盖。

## 7. 常见问题（FAQ）

| 现象 | 原因 | 处理 |
|---|---|---|
| 前端图片 404 | 后端未启动或跨端口 | 确认 8000 存活；前端走 Vite 代理或直连 |
| 任务一直 queued | worker 正在执行前序任务 | 串行设计，等待即可；任务列表可看排队 |
| 生成全黑/噪声 | 显存不足或模型损坏 | 查看任务 error；重启后端释放显存 |
| 上传失败 | 文件超 20MB 或非图片 | 压缩/转格式后重试 |
| SSE 断连 | 后端重启或网络中断 | 前端自动重连（EventSource 内建） |
