# 09 - 本地存储方案（moofile）

> 状态：已实施完成 ✅ · 日期：2026-10-22 · 参考：deepagents_acp/utils/moofile_util.py、api/history.py、api/timers_engine.py

## 1. 目标

解决 TaskManager 纯内存、服务重启丢失全部任务历史的问题；为任务记录与推理统计提供**本地持久化**，目录与数据模型完全对齐 moofile_base 规范，可被 moofile 管理界面直接识别。

## 2. 存储布局

```
qwen-2.1/db/
├─ db_tasks_<hash8>/        # 任务记录库
│   ├─ db.bson              # moofile 集合
│   └─ meta.json            # {id, name:"tasks", type:"normal", createdAt, updatedAt, trashed}
└─ db_stats_<hash8>/        # 推理统计库
    ├─ db.bson
    └─ meta.json
```

每个数据库一个目录 `db_<name>_<hash8>`（uuid4 hex 前 8 位），内部统一 `db.bson` + `meta.json`。

## 3. 数据模型

### 3.1 任务记录（db_tasks_*）

```json
{
  "id": "task_xxx",
  "type": "text-to-image | edit | outpaint | upscale",
  "status": "succeeded | failed | cancelled | interrupted",
  "model": "qwen-image-2.1",
  "prompt": "…",
  "params": { "width": 1024, "height": 1536, "num_inference_steps": 20, "seed": 2026 },
  "outputs": ["/api/outputs/…/output_01.png"],
  "elapsed_seconds": 46.2, "steps_per_second": 0.43, "model_load_seconds": 38.1,
  "error": null, "created_at": "…", "finished_at": "…",
  "recordType": "record"
}
```

### 3.2 推理统计（db_stats_*）

```json
{
  "id": "stat_xxx", "model": "z-image-turbo",
  "elapsed_seconds": 24.8, "steps_per_second": 0.32, "model_load_seconds": 12.4,
  "created_at": "…", "recordType": "record"

```

## 5. 关键设计

- 写时机：任务终态（succeeded/failed/cancelled）一次写入；不写中间态
- 并发：全部写操作走进程级 `threading.Lock`（deepagents_acp 同款）
- 恢复：启动 load_tasks() 倒序恢复 _history；queued/running → interrupted（"服务重启中断"）
- 依赖：`pip install moofile`
- 容量：任务记录单条 <2KB，查询默认倒序 limit 200
