# 10 - 主页作品展示设计（参考"灵感画廊 - AI Image Studio"）

> 状态：已实施完成 ✅ · 日期：2026-10-22 · 参考：用户提供参考站截图（1080x2460 移动端竖版）

## 1. 目标

新增**主页（作品展示画廊）**，作为产品首页；导航栏可在"主页 ↔ 工作台"之间切换。参考站为移动端竖版设计，本项目为桌面端 Web 工作台，**沿用其深色科技风格与信息架构，适配宽屏布局**。

## 2. 参考站设计语言提炼

| 参考站元素 | 提炼要点 | 本项目落法 |
|---|---|---|
| 深色科技背景 | 深底色 + 发光渐变 | 沿用现有 `--bg` / `--gradient-brand` 令牌 |
| 顶部导航 | 首页 / 创作台 / 画廊 / 定价 + 登录 + 开始创作 | 主页 + 文生图/编辑/放大/扩图 5 tab，右侧 GPU 徽标保留 |
| Hero 区 | 主标题 + 副标题文案，氛围感强 | 品牌标题 + 副标题 + 统计 chips + CTA「去创作」 |
| 分类标签条 | 全部作品 / 写实摄影 / 二次元…（横向胶囊） | 按任务类型：全部 / 文生图 / 编辑 / 放大 / 扩图 |
| 作品主体 | 多格卡片，提示词文字预览，图文结合 | 桌面瀑布网格（3-4 列），卡片 = 图 + hover 遮罩（提示词/模型/时间）+ 点击放大 |
| 底部信息栏 | 版权 / 备案 / 条款 | 沿用 AppFooter（视需要增强） |

## 3. 页面结构

```
┌──────────────────────────────────────────────┐
│ Header：Logo | 主页 文生图 编辑 放大 扩图 | GPU │
├──────────────────────────────────────────────┤
│ Hero：标题「探索无限创意灵感」+ 副标题         │
│       统计 chips：作品数 · 模型数 · 最近生成    │
│       CTA：进入工作台                          │
│ 分类条：全部 / 文生图 / 编辑 / 放大 / 扩图      │
│ 作品网格（瀑布流 3 列）：                       │
│   ┌──────────┬──────────┬──────────┐          │
│   │ 图片(主)  │ 图片     │ 图片     │          │
│   │ hover 遮罩│          │          │          │
│   │  prompt  │          │          │          │
│   └──────────┴──────────┴──────────┘          │
│ 空状态 / 加载态                                  │
├──────────────────────────────────────────────┤
│ Footer                                       │
└──────────────────────────────────────────────┘
Lightbox（点击放大）：遮罩 + 大图 + prompt/模型/类型 + 关闭
```

## 4. 数据源与合并逻辑

- `GET /api/outputs?limit=50`：作品 runs（stamp / path / images / prompt / created_at）
  - 每条 run 的每张图片 = 一张作品卡片
- `GET /api/tasks?limit=50`：任务历史（id / type / model / outputs / status）
  - 按 `outputs` 文件名 basename ↔ run.images 匹配，为作品卡片补充 **model / type / status**
  - 匹配不到则卡片只显示 prompt + 时间（type 显示为 run 级默认或空）
- 分类筛选 = 按 type 过滤；"全部"不过滤

## 5. 交互

- 卡片 hover：图片微放大 + 遮罩浮现（prompt 前 3 行 + 模型徽标 + 时间 + 类型徽标）
- 点击卡片：Lightbox 大图预览（ESC / 点击遮罩 / 关闭按钮退出；左右键翻上一张/下一张可选）
- 分类条点击即时过滤（纯前端）
- 刷新按钮重拉数据；拉取中显示骨架/loading
