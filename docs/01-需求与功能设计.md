# 01 · 需求与功能设计

> 项目：Qwen-2.1 AI 图像工作站（Web UI）
> 版本：v0.1（首版落地）
> 日期：2026-10-21

## 1. 背景

本地已完成 Qwen-Image-2.1（文生图 / 编辑 / 扩图）与 Real-ESRGAN（图像放大，ncnn-vulkan 快速超分）的
Python 封装（`utils/qwen_21_util.py`、`utils/realesrgan_util.py`；Qwen 引擎已切换为
`utils/qwen_21_gguf_util.py` —— stable-diffusion.cpp GGUF 子进程方案，见 docs/26），并在 RTX 3080 20G 上
验证通过。现需要一套 Web 界面，把封装能力产品化，覆盖"AI 直出海报 → 编辑 → 放大 → 扩图"
完整工作流。界面视觉参考已由 Qwen-Image-2.1 生成的 UI 原型图（4 张功能页）。

## 2. 目标

- 提供浏览器可用的图像工作站，四个功能页：**文生图 / 图像编辑 / 图像放大 / 图像扩图**。
- 复用现有 util，不改动模型推理主链路，只做 Web 化封装。
- 支持任务进度实时反馈（SSE）、GPU / 模型状态监控、历史输出浏览与下载。
- 工程化：前端 Vue3 + TypeScript（Vite），后端 FastAPI；文档先行，实施有据。

## 3. 用户故事

| ID | 故事 | 验收标准 |
|---|---|---|
| US-01 | 作为用户，我输入 prompt 与参数，点击"开始生成"得到海报 | 任务提交后进度条实时推进；完成后画廊展示结果图，可下载；记录耗时 |
| US-02 | 作为用户，我上传原图 + 编辑说明（可带画圈/mask）修改局部 | 编辑任务完成，返回结果图；支持 before/after 并排查看 |
| US-03 | 作为用户，我选择图片或文件夹做超分放大 | 单张/批量放大；批量任务展示文件级进度（完成/处理中） |
| US-04 | 作为用户，我上传原图选择目标比例与扩展方向做扩图 | 扩图结果展示，标注扩展区域方向 |
| US-05 | 作为用户，我随时看到模型加载状态与 GPU 显存占用 | 左侧栏实时显示各图像模型状态、显存条 |
| US-06 | 作为用户，我浏览历史生成结果 | 输出画廊按时间倒序展示，可下载任意历史图 |

## 4. 功能清单

### 4.1 文生图（text-to-image）
- 输入：prompt、负面 prompt、宽高比（1:1 / 2:3 / 3:4 / 16:9 / 9:16 等）、步数、seed（可留空随机）
- 输出：单张 PNG，保存至 `outputs/<stamp>/output_01.png` + `input_prompt.txt`
- 进度：按扩散步数实时上报（step/total）

### 4.2 图像编辑（edit / precise_edit）
- 输入：原图（上传）、编辑说明 prompt、标注方式（画圈 / 涂鸦 / 分离 mask，前端提供画圈工具或上传 mask）、步数、seed、是否合成保真（composite）+ 羽化半径
- 输出：编辑结果图
- 备注：合成保真模式圈外强制保持原图，物理上不模糊

### 4.3 图像放大（Real-ESRGAN upscale）
- 输入：单张图片、放大引擎（Real-ESRGAN 快速超分）、倍数（2x / 3x / 4x，默认 2x）
- 输出：放大图，结果区支持原图 / 放大图左右滑块对比
- 进度：阶段文本 + 百分比；ncnn-vulkan 推理不占 CUDA 显存

### 4.4 图像扩图（outpaint）
- 输入：原图（上传）、目标比例（16:9 / 9:16 / 1:1）、扩展方向（左/右/上/下/四周）、填充模式、扩图描述 prompt、步数、seed
- 输出：扩图结果
- 备注：原图等比放入目标画布一侧，留白区生成扩展内容

### 4.5 模型与 GPU 监控
- 各图像模型（Qwen-Image-2.1 / ERNIE / MOSS / FLUX.2 / Z-Image / SANA / Lumina）加载状态（未加载/加载中/已加载/已就绪）
- RTX 3080 20G 显存占用（allocated/reserved/max）、百分比
- 最近一次推理耗时、steps/s、模型加载耗时

### 4.6 历史输出画廊
- 按时间倒序列出 `outputs/<stamp>/`，展示每张图片缩略图与下载链接
- 展示关联 prompt 记录

## 5. 非功能需求

| 项 | 要求 |
|---|---|
| 显存约束 | RTX 3080 20G：**单 worker 串行推理**，杜绝并发 OOM；图像模型互斥驻留（qwen/z-image/ernie/moss 冲突时自动卸载）；放大走 Real-ESRGAN（Vulkan，不吃 CUDA 显存） |
| 性能 | 首帧 UI < 2s；模型懒加载，仅任务触发时加载 |
| 可观测 | 每任务记录 elapsed_seconds / steps_per_second / model_load_seconds，任务详情可查 |
| 端口 | 后端 8000，前端 5173（dev）/ 打包后由后端静态托管亦可 |
| 平台 | Windows（开发与运行目标），Python 3.12 venv |
| 安全 | 服务默认绑定 127.0.0.1；上传文件仅限图片扩展名；不暴露模型权重路径 |
