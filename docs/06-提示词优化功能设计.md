# 06 - 提示词优化功能设计（离线 LLM + GPU 推理）

> 状态：已批准实施 · 日期：2026-10-22 · 关联：docs/01~05（Web UI 多模型生成平台）

## 1. 目标

在文生图/图像编辑页提供"提示词优化"能力：调用**本地离线 LLM**，将用户输入的简短描述扩写为可直接用于扩散模型的详细提示词，通过 UI 弹窗预览并一键回填。

## 2. 模型选型

| 项 | 结论 |
|---|---|
| 模型 | **Qwen/Qwen3.5-4B-Instruct**（官方，Apache 2.0） |
| 架构 | Gated DeltaNet + Gated Attention 混合，4B dense，原生多模态 |
| 精度/显存 | BF16 ~8-10GB（GPU 推理）；本地路径 `models/Qwen3.5-4B-Instruct` |
| 指令跟随 | IFEval 89.8（4B 级第一梯队），中文强 |
| 推理方式 | **GPU（CUDA）+ 显存共存/卸载策略**（用户要求速度） |
| 依赖 | transformers 5.20 原生支持，零新依赖 |

### 选型理由
- 上一轮评估中用户提供的 `rodrigomt/Qwen3.5-4B-Uncensored-Aggressive`（第三方 abliteration 去审查版）被否决：特性无用、无安全护栏、第三方可信度低。
- 官方 4B 在"中文扩写 + 指令跟随 + 体积"三点上是最优平衡；BF16 8GB 在 3080 20G 上与小型图像模型可共存。

## 3. 显存共存/卸载策略（3080 20G）

LLM（~8GB BF16）与图像模型的共存矩阵：

| 图像模型（任务） | 峰值显存 | 与 LLM 共存(8+?) | 策略 |
|---|---|---|---|
| FLUX.2 Klein 4B | ~8GB | 16GB ✓ | **共存**，不卸 LLM |
| SANA-Sprint 1.6B | ~5GB | 13GB ✓ | **共存**，不卸 LLM |
| Z-Image Turbo | ~12.3GB | 20.3GB ✗ | 卸 LLM 再加载图像模型 |
| Qwen-Image-2.1 | ~19.5GB | ✗ | 卸 LLM 再加载图像模型 |
| 扩图（outpaint） | 同 Qwen-Image | ✗ | 卸 LLM 再加载 |

**规则（实现于任务分发层）**：
1. **提示词优化请求**：若 LLM 未加载 → 先卸载当前驻留图像模型（若有）→ 加载 LLM → 推理 → **LLM 驻留**（下次优化秒级响应）。
2. **图像任务**：若 LLM 驻留且目标模型为 `qwen-image-2.1` / `z-image-turbo` / `ernie-image` / `moss-image-sft` / `outpaint` → 先卸载 LLM；目标为 `flux2-klein-4b` / `sana-sprint-1.6b` → 保留 LLM 共存。
3. LLM 的卸载复用 `unload()` 模式（置 None + gc + `torch.cuda.empty_cache`）。

> 显存预估值来自实测：klein 8.0GB / sana 5.1GB / z-image 12.3GB / qwen-image 峰值 19.5GB。

## 4. 架构与接口

```
前端 TextToImageView.vue / EditImageView.vue
   │  POST /api/prompt/optimize {prompt, target_model}
   ▼
backend/app/routers/prompt.py          # 轻量同步推理放线程池
   ▼
backend/app/services/llm_service.py   # 懒加载单例 + 显存共存判断
   ▼
utils/llm_prompt_optimizer.py         # PromptOptimizer（GPU bf16、模板、超时）
   ▼
models/Qwen3.5-4B-Instruct            # 本地离线权重
```

**接口定义**：`POST /api/prompt/optimize`
```json
请求：{ "prompt": "夏日冰饮节海报", "target_model": "auto" }
响应 200：{
  "original": "夏日冰饮节海报",
  "optimized": "Professional advertising poster for a summer ice drink festival...",
  "elapsed_seconds": 1.8,
  "model": "qwen3.5-4b-instruct"
}
错误 4xx/5xx：{ "detail": { "code": "...", "message": "..." } }
```

- `target_model`: `auto | qwen-image-2.1 | flux2-klein-4b | z-image-turbo | sana-sprint-1.6b`，决定模板语言偏好（FLUX/SANA 输出英文详细描述；Qwen/Z-Image 中英混合；auto 默认中文描述+英文关键词）。
- 独立于 TaskManager 图像队列；同步推理经 `run_in_executor` 不阻塞事件循环。
- 超时保护：`max_new_tokens=256`、`temperature=0.7`，单次调用硬超时 30s。

## 5. Prompt 模板（System）

```
你是专业的 AI 图像生成提示词优化器。将用户描述扩展为可直接用于扩散模型的详细提示词。
规则：
1) 严格保留用户核心意图与主体，不得擅自增删主体或改变主题。
2) 补充细节：主体外观与动作、场景环境、光线氛围、构图布局、艺术风格、
   色彩基调、镜头语言（如适用）、质感纹理。
3) 输出为一段连贯文字，120-220 词，直接给出结果，不解释、不评价、不加前缀。
4) 目标模型 {target_model} 的偏好：{偏好描述}。
```

偏好描述映射：
- qwen-image-2.1 / z-image-turbo：中英混合，海报场景强调版式与可读文字
- flux2-klein-4b：英文为主，强调细节描述（无 prompt upsampling）
- sana-sprint-1.6b：英文为主，简洁明确
- auto：中文主体描述 + 英文风格关键词

## 6. UI 设计

- **入口**：提示词文本框右上角悬浮 ✨ 按钮（容器 relative，按钮 absolute 右上角）。
- **流程**：
  1. 点击 ✨ → 按钮 loading（"优化中…"），调 `/api/prompt/optimize`（携带当前输入框内容与所选模型）。
  2. 弹窗 Modal：左"原文"只读、右"优化结果"可编辑 textarea；顶部显示耗时/模型；底部「应用」「复制」「关闭」。
  3. 「应用」→ 优化结果回填输入框并关闭弹窗，**不自动提交**。
  4. 空输入时按钮禁用。
- **组件**：`frontend/src/components/PromptOptimizerModal.vue`（按钮+弹窗一体），`props: modelValue`（原文）、`modelId`（当前生成模型），`emit: apply(text)`。
- **接入**：TextToImageView.vue、EditImageView.vue 主提示词区。

## 7. 实施步骤

1. 下载模型：`hf download Qwen/Qwen3.5-4B-Instruct --local-dir models/Qwen3.5-4B-Instruct`（~9GB）。
2. `utils/llm_prompt_optimizer.py`：PromptOptimizer（GPU bf16、懒加载、模板、超时、gpu_memory_info）。
3. 后端：`schemas.py` 请求体、`services/llm_service.py`（含 `is_loaded/unload/should_unload_for(model)`）、`routers/prompt.py`、`main.py` 注册路由。
4. 任务分发（tasks.py）：图像任务执行前按 §3 规则决定是否 `llm_service.unload()`。
5. 前端：`PromptOptimizerModal.vue` + 两页接入 + `npm run build`。
6. 重启服务（0.0.0.0:8000），API 实测（中文短句/英文短句/空输入/共存场景），UI 验证。
7. 交付：图片/文档/截图 + 在线可访问。

## 8. 测试计划

| 用例 | 输入 | 预期 |
|---|---|---|
| 中文短句 | "夏日冰饮节海报" | 输出 120-220 词详细提示词，含风格/构图/光线 |
| 英文短句 | "a red fox in snow" | 输出英文详细描述 |
| 共存 | LLM 驻留 + klein/sana 任务 | 任务正常，显存 <20G |
| 互斥 | LLM 驻留 + qwen-image 任务 | 自动卸 LLM，任务正常 |
| 空输入 | "" | 400 校验错误 |
| 超长输入 | >4000 字符 | 400 校验错误 |
