# 23. 历史跳转与放大对比回显

日期：2026-10-24 ｜ 状态：已上线

## 功能
1. **放大历史点击 → 对比回显**：点击放大历史图片，左侧结果区以滑块对比展示「原图 / 放大图」（新放大任务起生效）。
2. **文生图历史跳转按钮**：每张缩略图新增 🔍去放大 / ✂去编辑，点击跳转对应页面并自动带入该图。

## 实现
- 后端三个端点 `/api/tasks/{upscale,edit,outpaint}` 新增可选 `src_stamp/src_image`（服务端引用，替代上传）；`_resolve_src()` 走作品库 db/images，回退 outputs/ 遗留。
- 两个放大 util（realesrgan/seedvr2）放大时在 run_dir 保存原图副本 `_input_original.png`（`_` 前缀天然不参与产物列表）。
- `/api/outputs` 的 run 增加 `source` 字段（存在原图副本时回填），前端据此决定滑块对比 or 单图。
- 前端三视图（Upscale/Edit/TextToImage）支持 `?src=&img=` query 解析；HistoryGallery 缩略图 hover 增加跳转按钮（@click.stop）。

## 修复的隐藏 bug
**migrate_legacy 类型覆盖**：启动扫描 outputs/ 时无条件 upsert 所有批次为 type=unknown，导致每次重启把已收编任务（text-to-image/upscale）全部覆盖。修复：仅收编未登记批次（`find(d.name)` 跳过）。历史 124 条记录已按 params 特征一次性修正类型（text-to-image/edit/outpaint/upscale）。

## 验证
- curl：upscale/edit 带 src 引用 → 入队成功；非法 src → 404。
- 新放大任务 run_dir 生成 `_input_original.png`；`/api/outputs?type=upscale` 该条 source 有值，旧记录 source 为空（前端单图降级）。
- 前端 `npm run build` 通过；后端已重启。

## 说明
- 旧放大记录无原图副本，点击后单图展示；后续新放大均有对比。
- 编辑/扩图菜单仍隐藏（用户此前要求），跳转按钮使用独立路由直达，不受影响。
