# 12 - 主页卡片与工作台结果区交互重构

> 状态：已实施（2026-10-22 完成，CDP 端到端验证通过）· 日期：2026-10-22 · 动因：主页卡片 hover 遮罩过重；文生图结果区与历史割裂；历史作品缺主页收录/删除管理

## 1. 需求拆解

| # | 需求 | 现状 | 目标 |
|---|---|---|---|
| 1 | 主页卡片 | hover 遮罩层（做同款/查看大图）+ 信息区 | 去掉遮罩；「做同款」常驻卡片右下角；整图点击放大 |
| 2 | 文生图结果区 | 结果面板（ImageGallery + OutputsPanel）与任务历史分开，配置列显示不全 | 结果区上下 50%：上半大图预览、下半图片历史（正方形缩略图 flex 排版） |
| 3 | 历史管理 | 历史图片无管理能力；主页展示全部作品 | 历史图片支持「加入/取消主页」「删除」；仅加入主页的作品展示到主页；点击历史图回填参数并上大图预览 |

## 2. 主页（需求 1）

### 2.1 交互
- 删除 `.card-hover` 遮罩（含 backdrop-filter/opacity 逻辑，一并清理死 CSS）
- 图片整卡可点击 → Lightbox（保留关闭/左右切换/Esc）
- 「✨ 做同款」小按钮常驻 `card-info` 的 meta 行**右下角**（仅 `type==='text-to-image'` 且有 `params`），点击 → reuse store → 跳工作台回填
- 主页数据改为 `GET /api/outputs?pinned=1`（仅已加入主页的作品）

### 2.2 卡片结构
```
.card
├─ .card-frame（@click → Lightbox）
│   └─ img（lazy + ?t= cache-buster + onerror 重试，保留）
└─ .card-info
    ├─ .card-prompt（2 行截断）
    └─ .card-meta
        ├─ 类型胶囊 / 模型 / 尺寸 / 步数
        └─ ✨ 做同款（右下角常驻，@click.stop）
```

## 3. 文生图结果区（需求 2）

### 3.1 布局
`result-panel` 内部改为上下分栏（`.result-split`，各 50%，上 1fr / 下 1fr）：

```
result-panel
├─ 标题行（结果 + 状态徽标 + 刷新）
├─ 上半 .preview-area（大图预览）
│   ├─ 生成中 → TaskProgressBar（保留）
│   ├─ 有空闲/选中图 → 大图 contain 展示 + prompt/meta 行
│   └─ 无 → 占位「输入描述，点击开始生成」
└─ 下半 .history-area（图片历史，可滚动）
    └─ 按批次分组（stamp 头 + 状态徽标）
        └─ 正方形缩略图 flex wrap（96px）
            └─ hover 操作：⭐ 加入/取消主页、🗑 删除（二次确认）
            └─ 点击缩略图 → ① 上大图预览 ② 回填参数到配置
```

- 配置列（360px）保持独立，不再被历史挤压（显示不全问题由上下分栏解决）
- `OutputsPanel` 从 result-panel 移除，由新的历史区替代；`TaskHistoryPanel` 保留在 ws-main 底部（任务文字日志，全子页通用）

### 3.2 大图预览状态
- 默认：最近一次生成成功图（`store.lastResult` 首图）或占位
- 点击历史缩略图：切换为选中图（URL + prompt + stamp + model/参数）
- 生成中：TaskProgressBar 优先

## 4. 历史管理与主页收录（需求 3）

### 4.1 数据模型（moofile 新库 `db_gallery_<hash8>`）
记录（仅存**取消主页**的条目；无记录 = 默认已收录主页）：

```json
{ "id": "gid_xxxx", "stamp": "20261022_125520", "image": "output_01.png",
  "pinned": false, "created_at": "..." }
```

- 「加入主页」= 删除该 (stamp, image) 记录（恢复默认收录）
- 「取消主页」= upsert `pinned:false` 记录
- 「删除」= 删除输出文件 + 删除记录；批次目录空则删除目录

### 4.2 后端 API

| 接口 | 方法 | 说明 |
|---|---|---|
| `GET /api/outputs?limit=50&pinned=1` | GET | `pinned=1`：过滤掉未收录图片；默认：返回全部并带 `pinned: boolean[]` 标记 |
| `POST /api/gallery/pin` | POST | body `{stamp, image}`：加入主页（删记录） |
| `POST /api/gallery/unpin` | POST | body `{stamp, image}`：取消主页（upsert pinned:false） |
| `DELETE /api/gallery/{stamp}/{image}` | DELETE | 删除文件 + 记录 |

- `OutputRun` 增加 `pinned: boolean[]`（与 `images` 一一对应）
- 新增 `backend/app/gallery_store.py`（沿用 db_store.py 的 MooFileUtil 模式，进程锁串行）

### 4.3 前端联动
- 新组件 `HistoryGallery.vue`（替代 OutputsPanel 进入 result-panel 下半）：
  - 加载 `GET /api/outputs`（全部 + pinned 标记）
  - pin/unpin：调 API 后局部刷新；删除：按钮变「确认删除」红态二次点击（不引入原生 confirm）
  - `emit('select', {url, stamp, image, prompt, params})`
- `TextToImageView`：
  - `onSelect` → ① 设置 preview 大图 ② `fillFromHistory(params)` 回填 prompt/negative/model/ratio/steps/seed（复用 DIMS 反查）
  - 无任务参数记录（早期批次）：只上大图，回填静默跳过
- 主页 `HomeView.load()` → `api.outputs(50, {pinned: 1})`

## 6. 验证

1. `npm run build` 零错误（vue-tsc 严格）
2. 后端：curl 验证 outputs `pinned=1` 过滤、pin/unpin/delete 幂等
3. CDP：主页做同款跳转回填仍正常；历史缩略图点击 → 大图切换 + 表单回填；pin/unpin 后主页增减；删除后文件消失
4. GUI 截图交付主页（无遮罩 + 右下角做同款）与文生图结果区（上下 50%）

## 7. 边界与取舍

- **默认收录**：历史批次无记录默认上主页（避免主页清空），取消后可再加入
- **删除为硬删**：删除输出文件与收录记录；任务文字记录保留（统计不缺失），但缩略图消失
- **早期批次无任务参数**：点击历史图仅上大图，不回填（提示词可在 meta 查看）
- 其他子页（编辑/放大/扩图）不改，共用新 gallery API 的收益后续再接入
