## 1. 设计语言

- **主题**：深色（`#0f1419` 底、`#1a222b` 面板、`#26303b` 边框），蓝色主色 `#3b82f6`（hover `#2563eb`），成功 `#22c55e`，警告 `#f59e0b`。
- **圆角**：8px（控件）/ 12px（卡片）；**间距**：4 基数列（4/8/12/16/24/32）。
- **字体**：系统栈 `Inter, "PingFang SC", "Microsoft YaHei", sans-serif`；代码/数值 `JetBrains Mono, Consolas, monospace`。
- 全局 CSS 变量定义于 `src/styles/variables.css`，深浅组件统一引用。

## 4. 状态管理（Pinia）

### 4.1 `stores/task.ts`
- state：`activeTasks: Record<taskId, TaskDetail>`（最近 20 条内存）、`taskIds: string[]`
- actions：
  - `submit(type, payload)`：调 API 提交 → 立即 `subscribe(taskId)`
  - `subscribe(taskId)`：`EventSource` 订阅 progress/status/done → 更新 state；done 后 close
  - `fetch(taskId)` / `fetchList()`
- 页面提交后本地立即显示"排队中"卡片，进度实时更新。

### 4.2 `stores/model.ts`
- state：`models`、`gpu`、`lastStats`
- action：`poll()` 每 5s 调 `/api/models`（页面可见时启动，unmounted 停止）。

## 7. 页面细节

### 7.1 文生图页
- 左：prompt 多行输入（示例占位）、负面 prompt、RatioSelector（1:1/2:3/3:4/16:9/9:16）、步数滑条（10~40，默认 20）、seed 输入（空=随机）、[开始生成] 主按钮（提交后禁用直至完成）。
- 右：TaskProgressBar + ImageGallery；空态提示"输入描述，点击开始生成"。

### 7.2 图像编辑页
- 左：原图上传（拖拽/点击，预览缩略图）、编辑 prompt、标注方式单选（画圈/涂鸦/Mask）、[上传标注图] 或 [mask 上传]、composite 开关 + feather 数值、[开始编辑]。
- 右：before/after 并排（左原图右结果，中间分隔线）。

### 7.3 图像放大页
- 左：模式切换 单张 / 批量文件夹；单张=上传图；批量=输入目录 + 输出目录（可空）；目标面积选择（1920×1080 / 2560×1440 / 2x）；DiT offload 开关；[开始放大]。
- 右：批量时文件级进度列表（文件名 + 状态徽章 + 进度条）；单张时 before/after。

### 7.4 图像扩图页
- 左：原图上传、目标比例（16:9/9:16/1:1/4:3/3:4）、DirectionChips（左/右/上/下/四周）、填充模式（白/灰/边缘延伸）、扩图描述 prompt、[开始扩图]。
- 右：结果图 + 扩展方向示意（结果下方标注"扩展区域：右"）。

## 9. 工程化要点

- Vite dev server 代理 `/api` → `http://127.0.0.1:8000`（避免 CORS；后端同时开 CORS 兜底）。
- `vue-tsc` 类型检查纳入构建：`npm run build` = `vue-tsc -b && vite build`。
- ESLint + Prettier（基础配置）；提交前 `npm run lint`。
- 构建产物 `frontend/dist/` 可被后端静态托管（`/`），实现单端口部署。
