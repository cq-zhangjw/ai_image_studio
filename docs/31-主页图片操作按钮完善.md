# 31 - 主页图片操作按钮完善（做同款全量 + 独立删除）（v1.3.5）

> 状态：已实施 · 日期：2026-10-25

## 1. 背景

- 主页（作品集）部分图片在历史记录中找不到（主页数据源为 db 作品库，任务记录仅保留近期），无法从历史侧删除 → 主页卡片需独立删除按钮。
- 主页"做同款"按钮此前 `v-if="it.type === 'text-to-image' && it.params"`：type 依赖 tasks 匹配（仅拉 50 条），较旧的图匹配不上 → 只有最新一张有按钮。

## 2. 变更

`frontend/src/views/HomeView.vue`：

- **做同款全量显示**：显示条件放宽为 `v-if="it.stamp"`（所有作品图都有）；`doReuse` 参数兜底 `it.params ?? {}`，未匹配到任务时按 params 推断类型（含 `_image_paths` → 图像编辑，否则文生图）。
- **独立删除按钮**：每张卡片做同款旁新增"删除"按钮；二次确认（首次点击变红"确认删除"，2.5s 内再点执行），调用与历史侧相同的 `api.deleteImage(stamp, image)`（文件名从卡片 URL 提取），成功后本地移除卡片 + 总数 -1，灯箱正显示该图时自动关闭。
- **布局修复**：`.card-meta` 增加 `flex-wrap: wrap`，按钮过多时换行而非被挤出卡片。

## 3. 验证

- `npm run build` 通过；主页截图确认各卡片"做同款 / 删除"按钮成对渲染。
- 删除链路复用 works/gallery 双位置清理，与历史删除一致。

## 4. 修复：做同款图片/参数未回填（覆盖时序）

- 根因①：主页 doReuse 未携带图片直链，且 TextToImageView 的 `applyReuse` 只填参数不设预览 → 历史加载完成后「默认显示最近一条」逻辑（`preview` 为空时触发）覆盖了回填的参数与画面。
- 根因②：EditImageView 完全不消费 reuse store（仅支持路由 src/img 带入）→ 编辑类"做同款"跳转后素材/参数丢失。
- 修复：
  - HomeView doReuse 在 params 中注入 `_preview_url`（本图直链）。
  - TextToImageView：`reuseApplied` 标记 + `fillParams` 支持 `_preview_url` 回显结果区；默认最近历史条件增加 `!reuseApplied`。
  - EditImageView：新增 `applyReuse`（type=edit），回填 model/steps/seed/编辑指令，并从 `_preview_url` 提取 stamp+img 复用路由带入链路（srcMode/srcStamp/srcImage/originalUrl + jumpedFromQuery 跳过历史覆盖 + 滑块拉到最右）。
- 验证：主页点第一张做同款 → 文生图页参数（模型/提示词/1536×864/风景）与图片全部回填，未被最近历史覆盖。
