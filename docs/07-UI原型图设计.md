# 07 - UI 原型图设计（Qwen-Image 生成）

> 状态：已批准实施 · 日期：2026-10-22 · 关联：docs/01~06

## 1. 目标

为 AI 图像工作站的核心功能页生成**高保真 UI 原型图**，用 Qwen-Image-2.1 直出视觉设计稿，作为前端界面迭代的参考基准。每个功能页对应一张原型图。

## 2. 统一设计规范（所有原型图共用）

| 维度 | 规范 |
|---|---|
| 主题 | 深色专业工具（背景 #0f1419，面板 #1a222b） |
| 主色 | 蓝 #3b82f6，成功绿 #22c55e，警示橙 #f59e0b |
| 布局 | 左侧窄导航栏（logo + 4 个功能项）+ 中间主操作区 + 右侧结果/画廊区 |
| 字体 | 现代无衬线（Inter/PingFang），中文界面文字 |
| 风格 | 干净、留白充足、圆角卡片（8-12px）、细边框、克制的阴影 |
| 画幅 | 16:9 横屏桌面界面（1536x864） |

## 3. 功能页原型与生成提示词

### 3.1 文生图页 `prototype_text_to_image`
布局：顶部 Logo「AI 图像工作站」+ 导航（文生图高亮/编辑/放大/扩图）；中间卡片：模型选择下拉（Qwen-Image-2.1 / FLUX.2 Klein / Z-Image / SANA-Sprint）、提示词大文本框（右上角✨AI优化按钮）、负面提示词、比例选择（1:1/2:3/3:4/16:9/9:16）、步数、种子、蓝色「开始生成」按钮；右侧画廊展示 2-3 张生成的海报缩略图。

### 3.2 图像编辑页 `prototype_edit`
布局：左侧上传区（原图预览 + 标注方式选择：画圈/涂鸦/Mask）；中间编辑说明文本框（✨按钮）+ 合成开关 + 羽化滑杆 + 「开始编辑」；右侧展示「编辑前 vs 编辑后」对比图。

### 3.3 放大页 `prototype_upscale`
布局：输入目录路径输入框 + 「浏览」按钮；目标面积下拉（1920x1080/2560x1440/Auto）；显存优化开关（DIT offload）；「批量放大」按钮 + 进度条；右侧文件列表（名称/原尺寸/目标尺寸/状态/耗时）与放大结果缩略图。

### 3.4 扩图页 `prototype_outpaint`
布局：原图上传缩略图（居中）；方向选择（上下左右/四周，选中态高亮）；扩图描述文本框；「开始扩图」按钮；右侧展示原图与扩图结果对比。

### 3.5 提示词优化弹窗 `prototype_prompt_modal`
布局：模态弹窗，顶部标题「提示词优化」+ 关闭按钮；中间左右分栏（左：原文只读面板；右：优化结果可编辑文本域）；底部按钮「复制」「关闭」「应用回填」；右上角徽标显示模型名与耗时。

## 4. 生成方案

- 工具：`utils/qwen_21_util.py` 的 `text_to_image`（Qwen-Image-2.1，20 步，1024x1536）
- 输出：`outputs/YYYYMMDD_hhmmss/input_prompt.txt + output_0X.png`（每功能一张，含耗时记录）
- 脚本：`tests/generate_ui_prototypes.py`
- 验收：文字（导航/按钮）清晰可读、布局符合上述分区、深色主题统一；每张图独立可看
